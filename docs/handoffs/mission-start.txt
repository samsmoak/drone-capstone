WHAT IT IS
──────────

A saved mission is flown later, from wherever the drone has been set down.
The drone's position IS the start: the mission is checked again from there
before anything arms. The inspection points never move with the drone —
they mark equipment.


SCOPE — DELIVERED
─────────────────

THE AGENT
  [x] Mission.from_start(position): the start moves to the drone, the points
      stay, points after the END POINT are dropped, return-to-start is off
      when there is an end point. The result is validated like any mission.
  [x] run_mission refuses before anything arms: Auto, a position fix, the
      plan valid, the plan valid AGAIN FROM THE DRONE (inside the fence,
      clear of obstacles, the leg to P1 and back clear), the battery for
      that path, the controller built. Replaces the old "within 0.30 m of
      the home mark, or refused" rule.
  [x] The from-start mission is what the controller is handed, what is kept
      with the flight (sessions/<id>/missions/<flight>.json) and what the
      pipeline reads.
  [x] GET /missions/{id}/from-drone: the same check, for the page.

② CHECK
  [x] "From where the drone is": the agent's answer every 2 s — safe to start
      here, or what to fix (the drone's spot, the leg from it) — with the room
      map drawn from the drone. Moving the drone by hand updates it.
  [x] The area confirmation in Auto reads "Drone on the floor and level…":
      heights are measured from the floor where it takes off, and from a
      bench every point would fly that much higher.

③ FLY
  [x] Start mission at the top, disabled with its reason; the agent's own
      refusals arrive as the page message.
  [x] The room map (2-D / 3-D) with the path from where the drone took off,
      the drone live at its height and heading, points done / current /
      ahead; progress beside it, only the points actually flown.
  [x] The whole flow goes full screen; while airborne its bar carries Land
      and the strip's own hold-to-stop emergency stop.
  [x] A mission counts as flying in the app shell, so the top strip shows
      Land and Emergency stop during one (it showed End session before).
