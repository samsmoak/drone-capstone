DECISIONS LOCKED IN

1. Steady climb and height hold without base stations uses the BAROMETER.
   The unassisted throttle law is replaced: the firmware's complementary
   estimator gives a baro height, and send_zdistance_setpoint(roll, pitch,
   yawrate, z) holds it. W/S move a target height gently; letting go holds it;
   landing descends under control. EXPERIMENTAL — baro height is noisy indoors
   (tens of cm) and prop wash disturbs it. Base stations remain the real fix.
2. The session history lives on the laptop (sessions/<id>/meta.json + a 1 Hz
   samples.csv covering the WHOLE session). Offline-first; never deleted by sync.
3. "Stay signed in" stores the Supabase refresh token in the app data folder,
   file mode 0600. Not the OS keychain (one fewer native dependency to bundle).
4. Fonts: Fraunces (display) + Inter (body), matching the portfolio. Bundled
   offline in the desktop app (@fontsource — the window's CSP blocks remote
   fonts, and the lab has no guarantee of internet); next/font on the web.
5. The web portfolio is a DOMAIN PORT of ../doctor-portfolio: single site (no
   multi-tenancy), admin gated by the existing operator role (no Google OAuth),
   team members as their own table shown beside each project.
6. Team names are the ones given: Yordanos, Hannah, Kevin, Reagan, and Samuel
   Enam Zih (last, with photo and https://samuelzih.savorar.com/). Roles and
   emails not given are left blank, not invented.


WAVE A — AGENT (backend/agent)

 1. Session: finish the manual activity when the controller lands or stops,
    whatever caused it (operator, guard, heartbeat) -> state READY, End works.
 2. Session: a low-battery guard verdict lands, then ENDS the session.
 3. Session: a tumble stops the motors, finishes the flight as aborted, READY.
 4. manual.py: unassisted law -> barometer height hold (zdistance setpoint).
 5. manual.py: W/S move target height at CLIMB_RATE; release holds it.
 6. manual.py: gentle liftoff — target starts at 0, climbs from the ground.
 7. manual.py: landing descends the target at a fixed rate, then stops.
 8. manual.py: keep the thrust unlock before the first setpoint.
 9. link.py: switch to the complementary estimator for unassisted flight,
    wait for it to settle, capture the baro ground height.
10. link.py: restore the Kalman estimator when the manual flight ends.
11. history.py: SessionLog — meta.json on start, samples.csv at 1 Hz.
12. history.py: summary at end (duration, flights, battery min/max, max
    height, outcome, abort reasons, samples).
13. history.py: list / read / samples-by-variable readers.
14. session.py: open the log on start, record flights, close on end.
15. cloud.py: restore a session from a stored refresh token.
16. auth store: save / load / clear the token, 0600, in the data folder.
17. session.py: restore_sign_in() at startup; sign_out clears the token.
18. rest.py: GET /history/sessions, /history/sessions/{id},
