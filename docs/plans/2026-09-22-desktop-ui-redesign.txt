DESKTOP UI REDESIGN — the 100 stages
====================================

A cosmetic pass over the whole desktop app: the web app's sidebar shell adapted
to a desktop window, sharp corners everywhere, and the Control page rebuilt as
two columns — a console on the left, the controls on the right.

NOT IN THIS PLAN, deliberately:
  - Every api.* call, KEY_MAP, the keyboard handlers, HoldToStop's 1000 ms,
    LiveConnection, the 50 Hz loop, anything under backend/. Untouched.
  - Splitting the battery and motor tests. One agent endpoint runs both
    (rest.py:334) — two buttons would need backend work.
  - A real camera datalink. There is no camera code in this project and the
    window's CSP cannot display a frame from the AI deck. The tab ships as a
    complete UI with an honest empty state.

WHY THE COUNT IS 100: the walk reached 8 nodes, which the checklist classes as
architectural. Phases, not a flat list.
