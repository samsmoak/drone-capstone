ARCHITECTURE AT A GLANCE — components, tech, connections
========================================================

The short version. Why anything is shaped this way: architecture.txt.

ONE SENTENCE

The Crazyradio is a USB dongle, so one laptop flies the drone and records
everything locally; Supabase and the website are where that record goes
afterwards.

WHAT EACH ONE DOES

  Flight agent    Owns the radio. Checks, guards, flight control, recording,
                  upload. The only thing that can move the drone.
  Desktop app     The operator's window. Starts the agent, shows the checks and
                  the live sensors, sends held keys. Touches no hardware.
  Database        Stores flights, sessions, audit trail, website content.
                  Decides who may read and write anything.
  Web app         Public site, operator dashboard, admin CMS.
  Release CI      Builds the installers and publishes them for download.

THE NUMBERS

  Telemetry stream        10 Hz, one shared subscription
  Manual control loop     50 Hz, generated by the agent
  Heartbeat timeout       0.5 s of silence → the agent lands
  Guard check             every 0.1 s while flying
  Upload                  every 60 s, or on demand
  Agent                   127.0.0.1:8765, localhost only
  Geofence                ±2.0 m, 1.0 m ceiling (defaults)


THE RULES THAT MATTER MOST

  1. Only the agent touches the radio.
  2. The CSV is written before anything is uploaded.
  3. The app sends intent (which keys are held), never setpoints.
  4. Authorization is row-level security in Postgres, not app code.
  5. Read the drone's own verdicts; never invent a threshold.


DESIGNED BUT NOT WIRED

  Web-queued missions     queued_missions() / claim_mission() exist and are
                          never called; Auto runs from the desktop app only
  Browser manual flight   the page opens /ws/manual; the agent serves /ws/live

  Crop-health predictions  best_lnn_stable.pt cannot be fed by this airframe:
                          1280 of its 1291 inputs are an embedding of a
                          PHOTOGRAPH, and the camera does not work

  Each of the three is broken for a reason that decides the work, not for want
  of an afternoon. architecture.txt has them in full; do not re-derive them.
