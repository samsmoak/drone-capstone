--------------------------------------------------------------------------------
1. WHAT IT IS
--------------------------------------------------------------------------------
"What this means at a particular point" (the owner). Every event becomes a
FINDING: a severity, a title, one sentence with when, where, how much and for
how long, and the frames taken during it. Every inspection point gets a
verdict: anomaly when a warning-or-worse finding overlaps its readings,
normal when it was analysed and nothing did, insufficient data otherwise.

3. DECISIONS
--------------------------------------------------------------------------------
• SEVERITY ON THE PEAK, AGAINST THE MEASURED MINIMUM the classifier reports in
  its features: info = an event (beyond any normal flight's wander); warning
  ≥ 2×; critical ≥ 5× (1.6 / 4.0 °C, 0.4 / 1.0 hPa). PROVISIONAL. Cooler
  counts like warmer. A pressure event with no measured height is at most
  info — a climb would look the same.
• WORDS FROM TEMPLATES, numbers exact — no LLM. Past 100× the noise it says
  "far beyond its noise" (a 0.009 °C-noise sensor made a 4 °C patch "436×").
• THE TELEMETRY DECIDES, THE IMAGE SUPPORTS (the owner). Frames within ±1 s of
  the stretch are attached (readable ones only). An image model's faulty
  label in that window → "supports"; all judged normal → "contradicts — the
  readings stand"; no model → "cannot tell", said. An image alone never
  makes an anomaly (tested).
• DETERMINISTIC FINDING IDS (uuid5 of flight, signal, start, end): processing
  a flight again replaces a finding instead of duplicating it — and never
  re-notifies.

--------------------------------------------------------------------------------
4. INVARIANTS
--------------------------------------------------------------------------------
• Exactly one verdict per inspection point, in order (the runner breaks an
  interpreter that skips one).
• A °F flight's minimum is a difference: 0.8 °C is 1.44 °F, never 33.44.
• An exact severity boundary counts as reached in either unit (1e-9).
• A point never reached is insufficient data, and says why.
