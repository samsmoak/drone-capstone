1. WHAT IT IS
--------------------------------------------------------------------------------
Story 4.2: a faulty sensor must not be mistaken for faulty equipment. The
cleaner marks each value it cannot trust, and the stages after it skip those
values (CleanResult.usable). It never edits or deletes a reading. On the
web's Raw view the flagged values are the points; the Clean view leaves them
out.

3. DECISIONS
--------------------------------------------------------------------------------
• REPLACED, NOT EXTENDED (the owner). On 66 real flights hampel@1 caught
  97.4 % of planted faults with 0.140 % false flags and 632 flags inside the
  planted heat ramps; robust@1 catches 100 % with 0.011 % and none.
• CORRECTED_TEMP IS JUDGED BY THE ENGINE'S OFFSET. It is raw_temp minus an
  offset the correction engine re-scales per thermal_state, so it STEPS when
  the state flips (median 4 times a flight, up to 79). hampel@1 called those
  steps spikes (294 of its 332 false flags). robust@1 checks raw − corrected
  against same-state neighbours, and corrected_temp inherits raw_temp's spike
  and stuck flags. With no raw_temp column it is judged on its own values.
• STUCK IS COUNTED ACROSS A GAP: a frozen sensor that loses a row is still
  frozen (hampel@1's 23 misses).
• POSITION AND BATTERY ARE CHECKED: untrusted (no base station received — the
  IMU coasting), implausible (faster than the flight guard's 2.0 m/s, imported
  from safety/flight_guard.py; a battery step over 1.0 V), out of range.
  After 0.5 s an estimate that stayed somewhere new becomes the reference.
• NO RATE-OF-CHANGE RULE: a real heat event is a sustained rise, which moves
  the median with it.
• The 114 remaining "false" pressure flags are ~0.1 hPa pulses at full-thrust
  bursts — the propellers, not the room — flagged on purpose so the
  classifier never reads them as the room.

--------------------------------------------------------------------------------
4. INVARIANTS
--------------------------------------------------------------------------------
• It flags; it never edits (the runner breaks a cleaner that changes readings).
• A held step and a slow rise are never flagged; the fixture flight gets no
  sensor flag; °F flags = °C flags (test_clean.py).
• A value keeps the first flag that fits: missing, out_of_range, untrusted,
  stuck, implausible, spike, gap.
• Spike windows never cross a gap; no module state — two flights may be
  cleaned at once.
