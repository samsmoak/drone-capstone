                       NEXT_PUBLIC_AGENT_URL. Keyboard map is in
                       docs/ROADMAP.md under "Keyboard control".
                       THE BROWSER SENDS HELD-KEY STATE, NOT ONE PACKET PER
                       KEYPRESS. The agent already generates the 50 Hz stream
                       and lands itself if the heartbeat stops. Do not
                       reimplement that in the browser.

  /app/settings        Geofence bounds, drone URI, agent reachability.

Rules that already apply (see CLAUDE.md):
  - Every async surface needs all four states. components/ui/states.tsx has
    them. A failed fetch must SAY so — never render nothing.
  - Read data through lib/queries.ts, write through lib/mutations.ts. Never
    call createClient() inside a component.
  - Chart colours come from the validated tokens in app/globals.css
    (--series-1..4). Do not invent colours. Light-mode aqua and yellow are
    under 3:1 contrast, so charts using them need direct labels or a table view.

--------------------------------------------------------------------------------
TRAPS THAT ALREADY COST TIME
--------------------------------------------------------------------------------

- Vercel Root Directory MUST stay "web". Unset, Vercel finds
  backend/agent/pyproject.toml, detects FastAPI, and tries to deploy the flight
  agent. Never give it a FastAPI entrypoint — the agent needs a USB radio and
  cannot run in the cloud.

- Hosted Supabase grants authenticated ALL privileges on public by default;
  local does not. Migration 0004 revokes and re-grants explicitly. If you add a
  table, check its grants on the HOSTED project, not just locally.

- A security test that only checks for denial proves nothing. Confirm the
  permitted path works too, or you cannot tell a policy from a missing grant.

- Seeding auth.users requires empty strings, not NULL, in the token columns.
  NULL makes every sign-in fail with a 500 that says "Database error querying
  schema" and looks nothing like a seeding problem.

- Do not run `supabase db reset` against the hosted project. It drops
  everything. Use `db push`.
